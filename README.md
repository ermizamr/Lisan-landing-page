# LISAN (ልሳን) — Official Landing Page

> **Offline-First Smart Speech & Machine Translation for Horn of Africa Languages**  
> *Amharic (አማርኛ) • Afaan Oromo • Tigrinya (ትግርኛ) • Somali (Soomaali) • English*

Official high-craft landing page for the [**LISAN Project**](https://github.com/ermizamr/LISAN).

---

## 🌟 Features

- **Editorial Aesthetic**: Warm Ethiopian highland atmosphere inspired by the Simien Mountains at dawn, featuring editorial typography (*Plus Jakarta Sans*, *Instrument Serif*, *Noto Sans Ethiopic*).
- **Interactive Speech Showcase**: In-browser audio playback of real test recordings with dynamic soundwave equalizers and speech repair disfluency normalization.
- **Scenario Explorers**: Triage & dialogue demonstrations across Clinics, Kebele Municipal Administration, Open Markets, and Banking.
- **Mobile Client Spotlight**: Showcases the native Flutter bidirectional conversation interface.
- **Zero Build Step**: Standalone static HTML5 + Tailwind CSS + Lucide Icons + Vanilla JS. Deployable instantly to GitHub Pages, Vercel, Netlify, or Cloudflare Pages.

---

## 🚀 Quickstart & Local Preview

### Option 1: Python HTTP Server (Zero Setup)
```bash
python -m http.server 3000
```
Then open [http://localhost:3000](http://localhost:3000) in your browser.

### Option 2: Run with FastAPI Backend
This landing page is also served directly from the LISAN backend server at:
```bash
uvicorn server:app --reload
```
And available at [http://localhost:8000/landing/](http://localhost:8000/landing/).
